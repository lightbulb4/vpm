# Lightbulb VPM Listing

This repository publishes Lightbulb's public, unadvertised package listing for VRChat Creator Companion.

## Add the listing

Use this URL in VRChat Creator Companion:

`https://lightbulb4.github.io/vpm/index.json`

Current packages:

- [Lightbulb World Tools](https://github.com/lightbulb4/lightbulb-world-tools), including AreaLit Occlusion Baker and Configuration Audit

The listing is rebuilt from package releases whenever `source.json` changes, when run manually, and on its scheduled refresh.
